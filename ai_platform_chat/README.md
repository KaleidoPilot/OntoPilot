# KaleidoPilot 用户对话端

独立于 `ai_platform_vue` 的用户前端，单独安装、启动、构建与部署。沿用 Vue 3、TypeScript、Vite 5、Element Plus；依赖锁定为原管理端当前安装版本。本项目不依赖原前端的源码或 node_modules。

## 启动

```powershell
cd ai_platform_chat
npm ci
npm run dev
```

访问 `http://127.0.0.1:3002`。使用现有管理员创建的外部用户账号登录，所属用户组须绑定启用的智能体。管理员账号继续使用原管理前端。

本地 `.env` 将 `/api` 代理到 `http://127.0.0.1:9711`，后端仍从原 `ai_platform_ht` 启动。若地址不同，在 `.env.local` 设置 `VITE_PROXY_TARGET` 后重启。

## 验证与部署

```powershell
npm test
npm run build
npm run preview
```

构建输出在本项目 `dist/`。生产环境默认请求同域 `/fijoAi`，需由部署方将该路径反向代理到现有后端，并关闭 SSE 响应缓冲、设置足够的读取超时。也可在 `.env.production.local` 设置完整的 `VITE_APP_BASE_URL`，此时后端需允许对应跨域来源。前端构建变量不可放密钥。本次未部署或修改网关。

## 功能与契约

- 登录：`POST /fijoAi/user/login`。使用返回的外部用户身份和 `agentKey`；缓存以 `fijo-chat-` 为前缀，与管理端隔离。
- 对话：`POST /fijoAi/agent/chat/stream`，请求 `{ key, query }`，接收 `metadata`、`content`、`error` 与 `[DONE]`。展示技能执行过程、Markdown 回答，支持停止接收、复制、Markdown 导出、错误后编辑问题及新对话。
- 技能：沿用 `/fijoAi/skill/private/*` 的私有技能管理、分享、技能库及用户密码修改逻辑。移植时只调整本项目登录缓存键。
- 左侧导航是常驻工作台，切换对话、技能和技能库时保留输入草稿与正在接收的回答，不弹离开确认。技能页面不重复展示顶部导航。
- 完整会话按账号、公司和智能体隔离保存在当前浏览器；发送问题后即出现在历史记录中，新对话保留旧会话，点击历史记录可重新打开。刷新后保留已有内容，但中断的流不会自动重试。存储不可用时显示提示。不同设备不自动同步，旧版本已丢失的记录无法恢复。
- 后端的 `session_id` 尚未用于上下文记忆，因此页面仍按单次问题执行；历史展示不等于模型具有跨轮记忆。
- 停止接收仅中止浏览器请求，不能保证撤销后台技能执行；错误不会自动重试，避免重复执行业务动作。
- 不提供尚无接口的后台任务、语音或附件功能。模型返回的任意 HTML 默认转义；只识别固定的执行过程容器，不允许脚本渲染。

对话直接沿用现有按 key 调用的接口权限契约；本项目未扩展服务端认证或公司隔离能力。公网开放前应由后端负责人确认该接口满足部署所需权限要求。
